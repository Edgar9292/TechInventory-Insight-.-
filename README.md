# TechInventory-Insight 🛠️

A Python-based tool to manage and analyze IT assets using SQLite.

## Features
- **Automated SQL Database**: Creates and populates an inventory system.
- **Data Integrity**: Uses Python string methods to clean input data.
- **Visual Reports**: Generates bar charts using Matplotlib to show inventory distribution.
- **Error Handling**: Implements `try...except` blocks for robust execution.

## Technologies Used
- **Python 3**
- **SQLite3**
- **Matplotlib** (for Data Visualization)

## How to Run
1. Clone the repo.
2. Run `python main.py`.
3. View the generated `inventory_report.png`.
